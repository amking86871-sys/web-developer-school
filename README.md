# Global Smart School

School website (demo content): Home, About, Programs, Admissions, Gallery, Notices, Contact.

## Files
- `index.html` - pages
- `style.css` - design
- `script.js` - menu, gallery filter, notices, forms
- `images/` - photos

## Run
Open `index.html` in a browser.

## GitHub Pages
1. Upload all files and the `images` folder to the root of the repository.
2. Go to Settings > Pages.
3. Source: "Deploy from a branch", branch `main`, folder `/ (root)`, then Save.

## Note
Forms are demo only and send nothing. Contact details, figures and notices are sample content.
Check that you have permission to use every photo before publishing.
